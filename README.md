# Direct control audit roots

Этот репозиторий хранит только канонические SHA-256 корни append-only журнала
изменений Директа. В нём не должно быть токенов, параметров кампаний, персональных
данных, снимков объектов или API-ответов.

Каждый новый корень публикуется отдельным JSON-файлом в `roots/`. Существующие
файлы не изменяются и не удаляются. Проверка сопоставляет корень локального
журнала с опубликованным файлом и его коммитом.

Ветка `main` предназначена только для append-only публикаций: force-push и
удаление ветки должны быть запрещены правилами GitHub.
